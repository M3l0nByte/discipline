# DISCIPLINE

Blocks the sites you keep losing hours to. Turns every clean day into XP, levels
and a streak you do not want to break.

Two pieces, one score:

- **A website** you just open. It shows your streak, level, XP and history.
- **A browser extension** for Chrome and Firefox that does the actual blocking and
  keeps the score. Install it and the website reads the same numbers.

No account, no server, no tracking. Everything lives in your browser.

---

## Open the site

**https://m3l0nbyte.github.io/discipline/**

That is the live dashboard. It works on its own straight away, saving to your

extension data instead — one score, wherever you open it.

## Install the extension

The extension is what actually blocks sites. Download this repo (green **Code**
button → **Download ZIP**) and unpack it, or clone it:

```bash
git clone https://github.com/M3l0nByte/discipline.git
```

### Chrome, Edge, Brave, Opera

1. Go to `chrome://extensions`
2. Turn on **Developer mode** (top right)
3. Click **Load unpacked** and choose the `dist/chrome` folder
4. Pin DISCIPLINE to your toolbar

### Firefox

1. Go to `about:debugging#/runtime/this-firefox`
2. Click **Load Temporary Add-on…**
3. Choose `dist/firefox/manifest.json`

(Firefox temporary add-ons reset when you restart the browser. For a permanent
install you would publish it to addons.mozilla.org — the manifest is ready for
that.)

Both builds live in `dist/`. They are generated by `npm run build`; you do not
need Node to use them.

## How it works

### Blocking

The extension ships with **119 blocked domains** — the big tube sites, cam sites,
fan platforms, hentai aggregators — plus **7 path rules** for the risky corners of
Reddit and X (`reddit.com/r/gonewild`, `x.com/search`, and so on). Those path
rules leave the rest of the site usable; only the listed paths go dark.

When you hit a blocked site you get a wall page, not a browser error: a breathing
pacer, four things to do instead, and a button to log the urge for XP.

Add your own from the dashboard. Three formats work:

| You type | What it blocks |
| --- | --- |
| `example.com` | the domain and every subdomain |
| `*.example.com` | subdomains only |
| `reddit.com/r/nsfw` | that path and everything under it |

Removing a domain from the dashboard removes it from the blocklist immediately.

### The score

| Source | XP |
| --- | --- |
| Every clean day | 25 XP base |
| Streak bonus | +2 XP per day of streak, capped at +60/day |
| Milestone day | Bonus on top: +25 (day 1) up to +5000 (day 365) |
| Beating an urge | +5 XP, up to 5 times a day |

Levels cost more each time: level 1 needs 100 XP, each level after that needs
60 XP more than the last. Ranks run:

`Recruit → Initiate → Apprentice → Adept → Disciplined → Monk Mode → Iron Will → Ascended → Legend`

So day one pays 52 XP (25 base, +2 streak, +25 First Blood). By day 30 a single
day is worth 385 XP. A 90 day run clears 6,000 XP before you count urges. Higher
level really does mean you have held out longer.

### Streaks, honestly

- **One tap a day.** "I stayed clean today" awards the day. It is idempotent, so
  the same day can never be farmed twice.
- **Forgotten days are covered.** If you check in after missing a day and never
  logged a relapse, the missed days are credited automatically. Forgetting the
  button does not cost you a streak.
- **Relapse resets the streak to zero** and keeps your total XP, level and clean
  day count. It is data, not punishment. The heatmap keeps the record so you can
  spot the pattern.

## Run the site locally

You only need this if you want to change the code.

```bash
npm start          # http://localhost:12000
npm test           # 27 tests
npm run build      # rebuild dist/chrome and dist/firefox
```

Requires Node.js 18 or newer. There are no dependencies.

## Project layout

```
public/                  the website (this is what GitHub Pages serves)
  index.html             the dashboard
  app.js                 UI + storage logic
  blocked.html           the wall page
  lib/
    engine.js            XP curve, levels, ranks, milestones
    blocklist.js         default blocklist + domain/wildcard/path matching
    state.js             check-ins, streaks, relapses, urges
extension/               extension source
  manifest.chrome.json   Chrome MV3 manifest
  manifest.firefox.json  Firefox MV2 manifest
  background.js          owns the state, builds the blocking rules
  content.js             the bridge between the website and the extension
  rulebuilder.js         blocklist entries -> declarativeNetRequest rules
  popup.*                compact mini-dashboard
  options.*              settings
  blocked.*              the wall page
dist/                    built extensions (committed, ready to load)
scripts/build-extension.js
tests/                   node:test suites
preview.js               tiny static server for local dev
```

`public/lib/*.js` is shared: the website loads it with `<script>`, the extension
bundles a copy, and the Node tests `require()` it. One source, no drift.

### How the website and extension link up

The page cannot call extension APIs directly, so it posts a message. A content
script on the site's pages relays that to the background worker and posts the
answer back. The page can only reach a fixed list of actions — read the summary,
check in, log a relapse or urge, edit the blocklist — nothing else.

If the extension is installed it is the source of truth, so your streak follows
you between the website and the toolbar popup. The first time the two meet, a
streak you collected on the website is handed to the extension so nothing is
lost. With no extension, the website saves to `localStorage` and works fine on
its own.

## A note on honesty

The XP only means something if the check-ins are real. The app cannot tell
whether you are being straight with it, and it is not trying to. Log the relapse
when it happens, look at the heatmap, and start the next streak. That is the
whole game.
